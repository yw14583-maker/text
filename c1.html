🔥 基础语法与表达式陷阱

核心常考

编译预处理不加分号

编译预处理（如 #define PI 3.14）不是C语言的一部分，不占运行时间，千万不能加分号 [cite: 9, 11]！

❌ 错误示范：#define PI 3.14;

概念误区

标识符与关键字

关键字不可以作为用户标识符。main, define, scanf 都不是关键字。特别注意：If 可以做为用户标识符，因为第一个字母大写了，所以不是关键字 [cite: 33, 34]。

进制挖坑

八进制与十六进制

C语言只有八、十、十六进制，没有二进制 [cite: 41]。八进制必须以 0 开头，十六进制以 0x 开头 [cite: 42, 44]。

⚠️ 注意：018 是非法的，因为八进制逢8进1，不可能出现数字8 [cite: 42, 43]。

口诀技巧

科学计数法 e

“e前后必有数，e后必为整数” [cite: 50]

例如：2.333e-1 是合法的，表示 2.333×10⁻¹ [cite: 49]。但 e3 或 2.1e3.5 都是非法的。

运算陷阱

连续比较 (x < y < z)

数学上 x < y < z 是连不等式，但在C语言中会从左到右算！

例如：int x=1, y=0, z=2; 判断 x<y<z。先算 1<0 为假（0），表达式变为 0<2，运算结果为真（1）[cite: 197, 198, 199]。

运算顺序

逗号表达式

逗号运算符优先级别最低 [cite: 78, 79]。表达式的数值是逗号最右边那个表达式的数值。

例如：(2, 3, 4) 的值是 4 [cite: 80]。注意 z = 2, 3, 4 是逗号表达式，z先被赋值为2 [cite: 82]。

🧠 数组、指针与函数进阶

内存概念

数组名是地址常量

数组名 a 表示第一个元素的地址（等价于 &a[0]）[cite: 348]。

⚠️ 极其重要：a 是地址常量！只要出现 a++ 或者 a = a+2 这种给 a 赋值的操作都是绝对错误的 [cite: 349]。

数组规则

数组定义与初始化

定义数组时，大小必须是常量（或符号常量），不能是变量！如 int a[x]; 是非法的 [cite: 337, 338]。

二维数组初始化时，列数绝对不能缺省，行数可以缺省 [cite: 341]。如 int a[][3]={1,2,3,4} 是合法的。

函数传参

形参与实参的传递

传数值的话，形参的变化不会改变实参的变化 [cite: 403]。

传地址（指针/数组）的话，形参的变化就会有可能改变实参的变化 [cite: 404]。这是考试必考重点 [cite: 402]。

💡 解析：选A。由于赋值运算符 "=" 的优先级高于逗号运算符 ","，所以 z = 2, 3, 4 等同于 (z = 2), 3, 4。此时整个逗号表达式的值是4，但 z 已经被赋值为 2 [cite: 82]。如果写成 z = (2, 3, 4)，z 的值才是 4 [cite: 81]。

5. 设有如下程序段：int x=1, y=0; if (!x) y++; else if (x==0) if (x) y+=2; else y+=3; 请问 y 的值是多少？

💡 解析：选A。这是文档中的原题陷阱。首先 x=1，!x 为假，不执行 y++ [cite: 238, 239]。接着执行 else if (x==0)，由于 x 是 1，所以 x==0 依然为假，其后跟随的整个嵌套 if 语句均不执行 [cite: 240, 241]。因此 y 保持原值 0。文档中所谓的“正确的是b为3”实际上是对内部嵌套逻辑的探讨，但因外层条件失败，最终y并未发生改变（此处根据C语言标准执行流程得出客观结果）。
